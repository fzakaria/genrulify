The input derivation

The fixture runs three GNU dd commands in Bash. Two write to the same path. The third publishes the result. 

dd if=header.txt of=bundle
dd if=body.txt of=bundle oflag=append conv=notrunc
dd if=bundle of="$out"

Give each write an SSA value

The append takes the previous bytes of bundle and the contents of body.txt. Folding a copy redirects its users to the original value.

What can Nixsplice convert today?

The importer accepts a pinned Bash builder running a straight-line sequence of GNU dd copies and appends. Shell builtins, general compiler invocations and directory outputs need additional semantics. The archive comparison checks the recorded inputs and outputs.
